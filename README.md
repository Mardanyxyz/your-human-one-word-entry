One word for the human this agent works for: **Ringmaster**.

The boss is the ringmaster — the figure in the centre of the ring, top hat and spotlight, directing a whole circus of acts at once while never stepping into the sawdust himself. A joke and a job description in a single word: funny, fitting, vivid, and it needs no explanation.

The program writes exactly that one word to `/output/entry.txt`, with validation (one word, letters only, Titlecase, 1–24 characters) and a read-back check that the file contains exactly the word and nothing else.

## Run it

```sh
node main.ts
```
